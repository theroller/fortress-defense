# Fortress Defense

A 2-player co-op game built by Finn (age 9) and Dad.

## How to Play

- **Finn** plays the **LEFT** side, **Ford** plays the **RIGHT** side
- Cannonballs fly in from both edges and try to knock down your fortress wall
- When a block gets destroyed, **tap near it** to repair it before the next cannonball gets through
- If a cannonball passes through a gap, the fortress loses health
- Survive as many waves as you can!

## Controls

- **Touch** (iPad): tap anywhere on your side at the height of the broken block
- **Click** (desktop): same idea with the mouse

## Run It

Open `index.html` in a browser. No build step, no internet needed.

Deploy to GitHub Pages by pushing to `main` — it'll serve automatically.

## Built With

- Vanilla JavaScript + Canvas API
- No libraries or dependencies
- Touch-first (iPad), works on desktop too
